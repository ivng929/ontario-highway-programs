# Analysis of Ontario Highway Program

## Overview

This project analyzes Ontario's Northern and Southern Highway Programs to explore the distribution, characteristics, and estimated costs of highway projects across Ontario.

The analysis combines data visualization, statistical hypothesis testing, and predictive modeling using R.

## Dataset

The datasets were obtained from Ontario Open Dataset

Source: https://data.ontario.ca/dataset/https-www-ontario-ca-page-ontarios-highway-programs

Two datasets were used:
- Ontario's Northern Highways Program
- Ontario's Southern Highways Program

## Files Explanation
| File | Description |
